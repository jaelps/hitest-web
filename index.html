CONEXÃO SEGURA

Acesso à API

Informe o token HITEST_API_TOKEN configurado nas variáveis de ambiente da Vercel. O token fica somente nesta sessão do navegador.

O frontend chama a API na mesma origem. O token não é incluído no bundle do site nem enviado para armazenamento persistente do navegador. Cadastro, leituras do heartbeat e histórico ficam no Redis sem expiração automática.
CONFIGURAÇÃO

Adicionar dispositivo

Não é necessário instalar programas nem manter um servidor local: a API na Vercel chama diretamente o IP público. Aceitamos HTTP em IPv4 público (porta 80) ou HTTPS em IP público IPv4/IPv6 (porta 443); domínios devem usar HTTPS. IPs privados e portas personalizadas são bloqueados. HTTP não criptografa comandos: prefira HTTPS. O IP e a porta precisam estar acessíveis da internet, com firewall configurado. A lista fica salva no Redis.
